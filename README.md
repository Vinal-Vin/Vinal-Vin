## 🧩 Featured Projects

### 🃏 [Planning Poker](https://github.com/Vinal-Vin/agile-planning-poker-app) · [Live demo](https://agile-planning-poker-app.vercel.app)
> *TypeScript · Next.js · Vercel*

Real-time agile estimation rooms: share a code like `brave-otter-42`, vote from any device, and reveal cards together.
- Host role with reveal and round control, handed to the longest-seated player if the host leaves
- Fibonacci and T-shirt decks, 3D card-flip reveals, floating emoji reactions, and consensus confetti
- Post-reveal stats: average, most picked, spread, and distribution

### 🥗 [PlateToFit](https://github.com/Vinal-Vin/plate-to-fit) · [Live demo](https://plate-to-fit.vercel.app)
> *Next.js (App Router) · TypeScript · Supabase · Tailwind CSS · PWA*

A private weekly meal-photo log and fitness goal tracker, installable to the iPhone Home Screen.
- Meal photos compressed client-side before upload
- Weekly PDF report export with meals grouped by day
- Hand-rolled PWA (manifest and service worker, no PWA library)

### 🂡 [Royale Blackjack](https://github.com/Vinal-Vin/blackjack-react) · [Live demo](https://blackjack-react-alpha.vercel.app)
> *React 19 · Vite · CSS/SVG*

A casino-grade Blackjack game with a Hi-Lo card-counting trainer.
- Real 6-deck shoe with Fisher–Yates shuffle and a cut card at 75% penetration
- Full action set: hit, stand, double, split, surrender, and insurance
- Chip-betting economy with a bankroll saved to `localStorage`

### 🏛️ [Clean Architecture](https://github.com/Vinal-Vin/clean-architecture)
> *C# · .NET 8 · Next.js*

A reference solution with API, application, core, and infrastructure layers on .NET 8, and a Next.js frontend.

### 📅 [Booking Slot](https://github.com/Vinal-Vin/booking-slot) · [Live demo](https://booking-slot-one.vercel.app)
> *Next.js · Tailwind CSS · shadcn/ui · Supabase*

A meeting-slot booking system for a delegation visit, with self-service cancellation and real-time slot availability.

### 📦 [Big Data Docker Stacks](https://github.com/Vinal-Vin/bigdata-docker-stacks)
> *Docker Compose · Kafka · Hadoop · Spark · Jupyter*

A one-command learning environment: Kafka with a web UI, HDFS/YARN/MapReduce, a Spark cluster, and Jupyter.
